# Re-Shikimori-App
Android client for anime website

[Trello](https://trello.com/b/TeSnqIHY/shimori)  
[Forum](https://4pda.to/forum/index.php?showtopic=903970)

## Build

```bash
./gradlew assembleDebug          # debug APK
./gradlew assembleRelease        # release (minify+shrink+zipalign)
```

Requires Java 17+ and Android SDK 35. Open in Android Studio and sync, or build from CLI.
